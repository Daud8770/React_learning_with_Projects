# React Learning with Projects

A collection of React projects built while learning React, from basics to advanced concepts.

Each folder in this repository is an independent React project with its own `package.json`.

## Projects

| # | Folder | Description |
|---|--------|-------------|
| 1 | `CounterApp` | Simple counter app to practice state and event handling |
| 2 | `Course` | Course listing app built with components and props |
| 3 | `CreatDummy/Dummy` | Practice project created to try out basic React setup |
| 4 | `DemoForm/demo-form` | Form handling demo using controlled components |
| 5 | `TestimonialSlider` | Testimonial / review slider component |
| 6 | `Tourism Plan` | Tourism plan cards app with dynamic data |
| 7 | `blog-context` | Blog app using the Context API |
| 8 | `blogs-context-2-starter` | Blog app (version 2) using Context API with pagination |
| 9 | `formapp/my-react-app` | Form application built with React |
| 10 | `random gif` | Random GIF generator using an API |
| 11 | `router app` | Routing practice using React Router |
| 12 | `router-project-studyNotation` | Multi-page project built with React Router |
| 13 | `top-course-starter` | Top courses app with filters and category selection |

## Tech Stack

- React
- JavaScript (ES6+)
- HTML and CSS
- React Router
- Context API

## How to run a project

1. Clone the repository:

   ```bash
   git clone https://github.com/Daud8770/React_learning_with_Projects.git
   ```

2. Go into the project folder you want to run:

   ```bash
   cd React_learning_with_Projects/CounterApp
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the app:

   ```bash
   npm start
   ```

   If the project was created with Vite, use `npm run dev` instead.
